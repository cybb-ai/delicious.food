# 煎好日訂單 → Google Sheets 串接

網站結帳送出後，訂單會透過 Google Apps Script（GAS）寫入你的 Google 試算表。

## 架構

```
網站結帳表單 ──POST(JSON)──▶ GAS 網頁應用程式 (doPost)
                                 │ 驗證欄位、以伺服器價格重算金額
                                 │ 產生訂單編號 JGD-日期-流水號
                                 ├─▶ 「訂單」工作表（一張訂單一列）
                                 ├─▶ 「訂單明細」工作表（一個品項一列）
                                 └─▶ （選用）Email 通知門市
網站 ◀──{ ok, orderId }──────────┘
```

## 部署步驟（約 5 分鐘）

1. 到 Google 雲端硬碟建立一份新的 **Google 試算表**，命名例如「煎好日訂單」。
2. 在試算表點選 **擴充功能 → Apps Script**。
3. 刪除編輯器裡的預設程式碼，把本資料夾的 `Code.gs` 全部貼上，按儲存。
4. （選用）把 `CONFIG.NOTIFY_EMAIL` 改成門市信箱，有新訂單時會寄信通知。
5. 上方函式選單選 **setup**，按 **執行**。第一次會要求授權，依畫面允許。
   完成後試算表會出現「訂單」「訂單明細」「每日統計」三個工作表。
6. 點右上角 **部署 → 新增部署作業**：
   - 類型：**網頁應用程式**
   - 執行身分：**我**
   - 存取權：**所有人**
7. 按「部署」，複製產生的網址（結尾是 `/exec`）。
8. 打開 `index.html`，找到這一行，把網址貼進引號內：
   ```js
   const ORDER_API_URL='';
   ```
   留空時網站維持「展示模式」，不會送出任何資料。
9. 推送到 `main`，GitHub Pages 部署後即生效。

> 之後修改 `Code.gs`，要用 **部署 → 管理部署作業 → 編輯 → 版本選「新版本」** 重新部署，網址才會維持不變。

## 試算表功能

| 功能 | 說明 |
| --- | --- |
| 狀態下拉選單 | 新訂單 / 製作中 / 可取餐 / 已完成 / 已取消，各有底色 |
| 狀態更新時間 | 修改狀態欄時自動記錄 |
| 「煎好日」選單 | 試算表上方的自訂選單，可批次把選取的訂單改狀態 |
| 每日統計 | 每天的訂單數、件數、營業額（不含已取消） |

## 安全設計

- **價格以 GAS 內的 `MENU` 為準**，前端送來的金額不會被採用。修改菜單或價格時，請同步更新 `Code.gs` 的 `MENU` 與 `index.html` 的 `products`。
- 同一筆送出（網路重試、連點）在 10 分鐘內不會重複建立訂單。
- 隱藏的機器人陷阱欄位，可擋掉簡單的垃圾訂單。
- 以 `=`、`+`、`-`、`@` 開頭的輸入會被轉成純文字，避免被試算表當公式執行。
- 品項數量上限：每項 50 件（`CONFIG.MAX_QTY_PER_ITEM`）。

## 上線前請注意

網站目前的 FAQ 與隱私權說明寫著「資料不會傳送到伺服器」。啟用串接後，訂單的姓名、電話、地址會存進你的 Google 試算表，請同步修改這些文字。
